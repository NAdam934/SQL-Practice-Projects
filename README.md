Gyakorló SQL fájl

A Gyakorlasok.sql tartalmazza azokat a lehívásokat, amelyeket az oktatás során megtanultam.

Két népszerű adatbázist használtam a feladatok megoldására, melyeket csatoltam a Repository-ba. Az egyik a Classic Models, amiben egy fiktív, model járműveket gyártó és árusító cég adatait tartalmazza.
A másik a Sakila adatbázis, mely filmeket, azoknak a bérlését és értékelését tartalmazza.
Továbbá saját gyakorló adatbázisokat is létrehoztam "gyakszi" és "TEST" néven.
